QUICK START:
===========

1. Test the scanner:
   python3 port_scanner.py localhost -p 80,443,22

2. Install system-wide (optional):
   sudo ./install.sh

3. Run demo (optional):
   ./demo.sh

4. View help:
   python3 port_scanner.py --help
